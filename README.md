## ダウンロード

**[→ 最新のリリースはこちら](../../releases/latest)**

| ファイル | サイズ | 何のためのもの |
|---|---|---|
| `AIxKendoDeep2-EnvCheck-0.1.0.zip` | **約6KB** | ⭐ **先にこちらを。** お使いの PC で動くかを確認します |
| `AIxKendoDeep2-0.1.0-beta-win64.zip` | **約191MB** | 本体 |

### 1. まず動作環境を確認する（約6KB・30秒）

`AIxKendoDeep2-EnvCheck-0.1.0.zip` を展開し、**`動作チェック.bat`** をダブルクリックしてください。
OS・空き容量・カメラ・ポートの空きを調べ、結果をその場に表示します。

**外部への通信は行いません。** 中身は PowerShell スクリプトなので、内容をそのまま読めます。

### 2. 問題なければ本体を入れる

`AIxKendoDeep2-0.1.0-beta-win64.zip` を展開し、**`AIxKendoDeep2.exe`** を実行するだけです。
**インストール作業は不要**で、フォルダごと移動・削除できます。

## 動作環境

- Windows 10 / 11（64bit）
- 空き容量 1GB 以上（展開後 約488MB）
- PC 内蔵カメラまたは USB カメラ（撮影機能を使う場合）

## 「Windows によって PC が保護されました」と出たら

個人や小規模の開発者が配布するソフトでは、Windows が警告を出すことがあります。
**不具合ではありません。**

1. 警告画面の **「詳細情報」** をクリック
2. 下に出てくる **「実行」** をクリック

ご不安な場合は、下の **SHA-256** をお手元のファイルと照合してください。

```powershell
Get-FileHash .\AIxKendoDeep2-0.1.0-beta-win64.zip -Algorithm SHA256
```

値が一致すれば、こちらが配布したものと同じファイルです。
各リリースの `SHA256SUMS.txt` に正しい値を載せています。
