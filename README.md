## ダウンロード

**[→ 最新のリリースはこちら](../../releases/latest)**

| ファイル | サイズ | 何のためのもの |
|---|---|---|
| `AIxKendoDeep2-EnvCheck-0.1.0.zip` | **約6KB** | ⭐ **先にこちらを。** お使いの PC で動くかを確認します |
| `AIxKendoDeep2-0.1.2-beta-win64.zip` | **約191MB** | 本体 |

### 1. まず動作環境を確認する（約6KB・30秒）

`AIxKendoDeep2-EnvCheck-0.1.0.zip` を展開し、**`動作チェック.bat`** をダブルクリックしてください。
OS・空き容量・カメラ・ポートの空きを調べ、結果をその場に表示します。

**外部への通信は行いません。** 中身は PowerShell スクリプトなので、内容をそのまま読めます。

### 2. 問題なければ本体を入れる

`AIxKendoDeep2-0.1.2-beta-win64.zip` を展開し、**`AIxKendoDeep2.exe`** を実行するだけです。
**インストール作業は不要**で、フォルダごと移動・削除できます。

## 🔄 新しい版が出たときは（データの引き継ぎ）

**自動更新はしません。** 署名のないソフトの自動更新は、それ自体が警告の対象になるためです。

1. 新しい ZIP を展開する（**古いフォルダは消さずに残す**）
2. 古いフォルダの中の **`data` フォルダ**を、新しいフォルダへ**そのままコピー**する
3. 新しいフォルダの `AIxKendoDeep2.exe` を起動し、動画が見えることを確認する
4. 確認できたら古いフォルダを削除する

`data` に撮ったもの・切り抜き・比較の記録がすべて入っています。
**フォルダごと別の PC へ持って行くこともできます。**

## 先にお伝えしておきます（警告は必ず出ます）

知らずに見ると「怪しいソフト」に見えてしまうので、先にお伝えします。

| 出るもの | どうすればよいか |
|---|---|
| **「Windows によって PC が保護されました」** | **「詳細情報」→「実行」** |
| **「Windows セキュリティの重要な警告」**（ファイアウォール） | **「プライベート ネットワーク」だけにチェックして許可。パブリックは不要**です |
| ウイルス対策ソフトが隔離した | フォルダを除外設定に入れてください |

⚠ **ソフトの名前は暫定です。** 正式名が決まると実行ファイル名が変わり、Windows は別のソフトとして扱うため、**警告がもう一度出ます。**

ご不安な場合は、`SHA256SUMS.txt` の値をお手元のファイルと照合してください。

```powershell
Get-FileHash .\AIxKendoDeep2-0.1.2-beta-win64.zip -Algorithm SHA256
```

値が一致すれば、こちらが配布したものと同じファイルです。
各リリースの `SHA256SUMS.txt` に正しい値を載せています。

## ご意見をお聞かせください

**このソフトは、剣道を指導されている方の声で形を変えていきます。**

とくに次の点を教えていただけると助かります。

| 聞きたいこと | なぜ |
|---|---|
| **動作環境チェックの結果** | `動作チェック結果.txt` をそのまま送ってください |
| **撮った動画の fps** | ライブラリのカードに出ています。**スローモーション専用モード**で撮ると解析できないことがあります |
| ⭐ **面うち・胴うちなど素振り以外の技で、技の検出が合っているか** | **実素材が無く未検証です。** 合わない例の動画をいただけると直せます |
| 切り抜き・技ごとの分割で困った点 | 操作の分かりにくさは使った方にしか見えません |
| レポートに載せたいのに載っていない数値 | 指導で実際に使う数値を知りたいためです |

もちろん「ここが使いにくい」「こういう見せ方がほしい」も歓迎します。
うまく動かない場合は **Windows のバージョン**を添えてください。
